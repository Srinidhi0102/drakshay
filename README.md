# Dr Akshay Jathkar - Orthopaedic Surgeon Website

A professional, responsive website for Dr Akshay Jathkar's orthopaedic surgery practice.

## 🏥 About

This website showcases Dr Akshay Jathkar's orthopaedic services, qualifications, and provides patients with easy access to appointment booking and health information.

## ✨ Features

- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX** - Clean, professional medical aesthetic with bone-themed design elements
- **Interactive Blog** - Expandable health articles with orthopaedic advice
- **Image Gallery** - Before/after procedure photos with slider functionality
- **Contact Integration** - WhatsApp and phone integration for easy appointments
- **SEO Optimized** - Meta tags and semantic HTML for better search visibility

## 🔧 Customization

### Logo
- Replace `images/logo.png` with your practice logo
- Logo appears in header, hero card, and footer sections

### Gallery Images
- Add procedure photos to `gallery/` folder
- Update `gallery.html` with new image references
- Images should be named `image-1.jpg`, `image-2.jpg`, etc.

### Contact Information
- Update phone number in HTML files (currently: +91 95520 94093)
- Update email address (currently: youremail@example.com)
- Update clinic address in footer sections

### Colors
- Primary blue: `#3b82f6`
- Text colors: `#0f172a`, `#64748b`
- Background: `#f8fafc`, `#ffffff`
